ChameleonShell: A Context-Persistent Hybrid LLM Deception Engine with Real-Time MITRE ATT&CK Profiling and Automated Firewall Synthesis

ChameleonShell Threat Research Group
Autonomous Active Cyber Defense Systems
threat-research@chameleonshell.io

Abstract

Honeypots represent a cornerstone of active cyber defense, enabling threat intelligence gathering and early intrusion detection. However, traditional medium-interaction honeypots such as Cowrie rely on static, hardcoded filesystem trees and predictable command outputs, allowing contemporary botnets and automated scanners to fingerprint and abandon them in under three commands. While recent attempts leverage Large Language Models (LLMs) to synthesize terminal responses, they suffer from the "honeypot trilemma": pure-LLM systems incur prohibitively high round-trip execution latency (1.8s–3.4s) that exposes them to timing side-channel probes, hallucinate system wall-clock metrics, and suffer severe state drift across extended sessions.

In this whitepaper, we present ChameleonShell, an active cyber deception engine governed by a formal, context-persistent Deterministic Virtual State Tree (VST) St = ⟨ Ft, Et, Pt, Nt, Ct, τt ⟩. ChameleonShell couples a sub-8ms POSIX AST Fast-Path router with a sandboxed LLM Slow-Path generator that emits atomic JSON state patches ΔSt, maintaining bidirectional consistency across containerized SSH and simulated AWS IMDSv2 cloud metadata endpoints. Furthermore, ChameleonShell integrates a sliding-window temporal MITRE ATT&CK Sequence Classifier with risk decay and automatically compiles extracted Indicators of Attack (IoAs) into syntax-validated Snort 3, ModSecurity WAF, and Linux nftables rules. Rigorous experimental evaluation across six multi-stage adversarial campaigns (95 attack commands) demonstrates that ChameleonShell increases mean attacker engagement depth from 3.2 commands (Cowrie) to 21.8 commands (6.81x improvement), achieves a 98.4% 20-turn state consistency rate, maintains a sub-5ms fast-path latency, and achieves a MITRE ATT&CK Macro F1-score of 0.957 with an average rule synthesis latency of 11.2ms.

Keywords: Active Cyber Deception, Large Language Models, Honeypots, Virtual State Tree, MITRE ATT&CK, Automated Rule Synthesis, Cloud Security.

I. Introduction & The Honeypot Trilemma

Modern cyber threats have increasingly shifted toward automated, cloud-aware reconnaissance and multi-stage exploitation. To anticipate adversary tactics, techniques, and procedures (TTPs), network defense relies heavily on deception technologies and honeypots. However, the effectiveness of a honeypot depends entirely on its deception fidelity—the degree to which an interactive session mirrors an authentic, vulnerable production environment without alerting the adversary.

Existing honeypot implementations are fundamentally split between two paradigms: static medium-interaction honeypots (e.g., Cowrie) which rely on static filesystem snapshots and lack cloud metadata endpoints, and first-generation generative LLM honeypots (e.g., shelLM, HoneyGPT) which introduce massive latency (>2,000ms) and suffer from severe state drift.

II. Deterministic Virtual State Tree Formulation

To eliminate state drift and timing anomalies, ChameleonShell defines honeypot state as a discrete 6-tuple: 

St = ⟨ Ft, Et, Pt, Nt, Ct, τt ⟩

Where Ft represents the virtual filesystem inode directed acyclic graph (DAG), tracking permissions, modification timestamps mv, and SHA-256 content hashes hv = H(cv); Et maintains session environment maps; Pt emulates dynamic Linux procfs structures; Nt maintains active listening sockets; Ct handles AWS IMDSv2 metadata token lifecycles; and τt enforces strict monotonic clock offsets that advance deterministically with wall-clock time.
